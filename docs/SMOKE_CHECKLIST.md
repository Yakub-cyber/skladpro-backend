Прогонять перед деплоем на VPS. Юнит-тесты (backend 143, web 264, mobile 95, POS smoke 10, desktop 37) уже зелёные — здесь ловим то, что вылезает только в живой интеграции.

## Быстрая подготовка

```
cd D:\Claude\skladpro-backend
pwsh scripts/dev-up.ps1              # создаст БД + .env + миграции
npm run dev                          # API на :8787 в отдельном терминале
node scripts/e2e-smoke.mjs http://127.0.0.1:8787  # 35 проверок
```

Клиенты параллельно в отдельных терминалах (все на localhost):
- `cd D:\Claude\skladpro && npm run dev` — веб на :5173
- `cd D:\Claude\skladpro-admin && npm run dev` — админка на :5174
- `cd D:\Claude\skladpro-pos-desktop && npm run dev` — Electron
- `cd D:\Claude\skladpro-mobile && npx expo start` → `a` (Android) — при этом в `.env` мобилки поставить `EXPO_PUBLIC_API_URL=http://<IP-ноутбука-в-Wi-Fi>:8787`
- Аналогично `cd D:\Claude\skladpro-pos && npx expo start`
